# 1. IMPORTANT DEVELOPMENT RULE

Do NOT attempt to build everything in one giant step.

Build the project in phases.

For each phase:

1. Implement the functionality.
2. Run the application.
3. Test it.
4. Fix errors.
5. Verify the database.
6. Verify the APIs.
7. Verify the UI.
8. Only then continue to the next phase.

If something is broken, STOP and fix it before continuing.

At the end of every phase, report:

```text
PHASE X COMPLETE

Implemented:
...

Files changed:
...

Tests:
...

Result:
PASS / FAIL

Next phase:
...
```

Do not claim something works unless you actually tested it.
